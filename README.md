# AFTERGLOW

A responsive one-page nightlife concept built as a dependency-free static site. It is ready for local review now and can later be connected to GitHub and imported into Vercel.

## Local preview

```powershell
npm run dev
```

Open `http://localhost:4173`.

## Project structure

- `index.html` contains the page content and accessible structure.
- `styles.css` contains the visual system, responsive layouts, and motion.
- `script.js` handles navigation, scroll effects, and the guest-list prototype.
- `assets/` contains the supplied nightlife photography.
- `vercel.json` adds production caching for image assets.

## Before launch

Replace the concept name, address, hours, event lineup, and social links. Connect the guest-list form to the chosen booking service or API. After review, push the repository to GitHub and import it into Vercel as a static project with no build command.
